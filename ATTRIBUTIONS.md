## Maps

- Interactive web maps are rendered with [MapLibre GL JS](https://maplibre.org/), an
  open-source WebGL map renderer distributed under the BSD 3-Clause license.
- Map styles and hosted vector tiles are supplied by
  [OpenFreeMap](https://openfreemap.org/) using the OpenMapTiles schema and geographic data
  from [OpenStreetMap](https://www.openstreetmap.org/copyright).
- Required on-map attribution is provided by the MapLibre attribution control from the
  OpenFreeMap source metadata: **OpenFreeMap © OpenMapTiles Data from OpenStreetMap**.

Do not remove, obscure, or disable the attribution control on any map surface.
